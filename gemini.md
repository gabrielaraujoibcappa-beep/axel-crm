# Project Constitution: Axel CRM

## 1. System Invariants & Rules

1. **Multi-Tenancy Isolation**:
   - Every domain entity MUST inherit from `BaseEntity` (`backend/src/main/java/com/axelcrm/commons/BaseEntity.java`).
   - Tenant context MUST be retrieved from `TenantContext.getOrganizationId()`.
   - All repository queries accessing domain data MUST include `organization.id` and `deletedAt IS NULL`.
   
2. **Data & Schema Integrity**:
   - Soft deletes only: never run `DELETE FROM table`. Always update `deletedAt = now()`.
   - Database migrations MUST be managed exclusively via Flyway (`backend/src/main/resources/db/migration`).
   - Primary Keys are UUIDs generated by the application / UUIDv4.

3. **API Contract**:
   - REST endpoints live under `/api/v1/`.
   - Standard DTO structure: Java `record` for Request and Response objects.
   - Uniform error response: `{ "error": "msg", "status": 400, "timestamp": "..." }`.

4. **Frontend Architecture**:
   - Angular 18 standalone components only (no NgModules).
   - Lazy loading for all feature modules via `loadComponent` / `loadChildren`.
   - Communication via `BaseService<T>` with `authInterceptor` handling tokens.
