# Project Memory: Axel CRM Onboarding & Architecture Blueprint

## System Overview
- **Project**: Axel CRM (Multi-tenant CRM / ERP for Sales, Operations & Finance)
- **Stack**: Angular 18 (Standalone, Material, Tailwind/SCSS) + Spring Boot 4.0 (Java 21, Spring Data JPA, Flyway) + PostgreSQL 16
- **Architecture**: Multi-tenant with JWT-embedded organization claims, ThreadLocal context, soft deletes, and REST API.
