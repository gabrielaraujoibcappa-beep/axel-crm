# 02 — Conhecendo a tela

Todas as telas do sistema seguem a mesma estrutura. Depois de entender esta página, você já sabe operar qualquer módulo.

## O menu lateral

À esquerda ficam os módulos, agrupados por área:

| Grupo | O que tem dentro |
| --- | --- |
| **Painel** | A tela inicial com os indicadores |
| **CRM** | Prospecção, Agenda, Parceiros / Indicadores, Clientes, Contatos, Leads, Negócios, Pipelines |
| **Operações** | Projetos, Produtos, Contratos, Processos, Tarefas, Propostas, Campanhas, Tickets, Documentos |
| **Financeiro** | Faturamento, Transações, Plano de Contas, Relatórios, Contas Bancárias, Horas, Comissões |
| **Admin** | Usuários, Integrações |

Clique no ícone de menu (☰), na barra superior, para recolher a lateral e ganhar espaço na tela. O grupo **Admin** só aparece para administradores.

## A barra superior

Da esquerda para a direita:

- **☰** — recolhe ou expande o menu lateral
- **Trilha de navegação** — mostra onde você está (por exemplo, *Clientes › Detalhe*) e permite voltar clicando em qualquer etapa
- **Sol / lua** — alterna entre tema claro e escuro
- **Sino** — notificações
- **Avatar** — perfil, tutorial e sair

## Notificações

Clique no sino para ver os avisos do sistema. Os não lidos aparecem destacados. Clicar em um aviso o marca como lido; **Marcar todas como lidas** limpa a lista de uma vez. O sino se atualiza sozinho enquanto você trabalha.

## Cronômetro de horas

O botão redondo flutuante, no canto inferior da tela, é o cronômetro — ele acompanha você em qualquer módulo.

1. Clique no botão para abrir.
2. Escolha o **Projeto / Perícia** em que está trabalhando.
3. Descreva o que está fazendo (por exemplo, *Análise de documentos CNJ*).
4. Clique em **Iniciar**.

Enquanto roda, o botão fica destacado. Ao terminar, clique em **Parar** e depois em **Salvar Tempo** — o apontamento vai para **Financeiro › Horas**. Se preferir descartar, use **Zerar**.

> O botão **Iniciar** só habilita depois que você escolhe um projeto. Sem projeto, não há onde lançar as horas.

## O padrão das telas de listagem

Quase todos os módulos usam o mesmo formato:

**Indicadores no topo.** Alguns números-resumo do módulo — por exemplo, em Clientes: total, ativos e inativos.

**Botão de criar.** Sempre no canto superior direito, com o nome do que será criado.

**Tabela.** Uma linha por registro. O rodapé permite escolher quantas linhas ver por página e navegar entre elas. Clicar no título de uma coluna ordena por ela.

**Ações na linha.** À direita de cada linha ficam os botões de ação. Os mais comuns:

| Ícone | Ação |
| --- | --- |
| ✏️ lápis | Editar o registro |
| 👁️ olho | Abrir a tela de detalhe |
| 🗑️ lixeira | Excluir |

Módulos específicos acrescentam suas próprias ações — copiar link, baixar PDF, converter em projeto — sempre com um texto explicativo quando você passa o mouse por cima.

## Criar e editar registros

Criar e editar abrem a mesma janela de formulário. Campos marcados com asterisco são obrigatórios: sem eles o botão **Salvar** não libera.

Ao salvar, uma faixa aparece no rodapé confirmando (*Salvo com sucesso!*) ou avisando de erro. Se der erro, os dados que você digitou continuam na tela — corrija e tente de novo.

## Excluir registros

O sistema pede confirmação antes de excluir. Registros excluídos saem das listagens, mas continuam guardados no banco de dados — nada é apagado de forma definitiva. Se algo foi excluído por engano, o administrador pode recuperar.

## Telas de detalhe

Clientes, Leads e Projetos têm tela própria, organizada em abas. Por exemplo, no cliente:

| Aba | Conteúdo |
| --- | --- |
| **Dados Cadastrais** | Contato, endereço e notas internas |
| **Histórico & Interações** | Linha do tempo de tudo que aconteceu com o cliente |
| **Arquivos & Anexos** | Documentos anexados, com baixar e excluir |
| **Oportunidades & Tarefas** | Negócios e tarefas ligados ao cliente |
| **Propostas & Projetos** | Propostas enviadas e projetos em andamento |

A seta no canto superior esquerdo volta para a listagem.

## Formatos

Valores em reais (R$ 1.234,56) e datas no formato brasileiro (dd/mm/aaaa). Campos de data abrem um calendário — você pode digitar ou escolher no calendário.
