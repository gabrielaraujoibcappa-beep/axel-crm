Guia de uso do sistema para quem opera o dia a dia: equipes de vendas, operações e financeiro.

Este manual não exige conhecimento técnico. Ele descreve o que cada tela faz, como executar as tarefas mais comuns e o que esperar de cada ação.

## Antes de começar

O Axel CRM funciona no navegador — não há nada para instalar. Use um navegador atualizado (Chrome, Edge ou Firefox) em um computador; a tela foi desenhada para uso em monitor, não em celular.

Cada empresa tem seu próprio espaço no sistema. Você só enxerga os dados da organização à qual sua conta pertence.

## Como usar este manual

Se você está começando agora, leia os capítulos 01 e 02 e depois vá direto ao capítulo 08, que percorre um caso completo do início ao fim. Os capítulos 04 a 06 servem como consulta: procure a tela em que você está e leia só aquela seção.
