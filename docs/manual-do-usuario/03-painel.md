# 03 — Painel

O **Painel** (ou Dashboard Executivo) é a tela inicial. Ele responde, em uma olhada, como o negócio está indo.

## Escolher o período

No topo, o seletor permite ver os números por **mês**, **trimestre** ou **ano**. Todos os gráficos acompanham a escolha.

## Os indicadores

Os cartões coloridos no topo mostram:

| Indicador | O que significa |
| --- | --- |
| **Clientes Ativos** | Quantos clientes estão ativos na base |
| **Total de Leads** | Quantos leads existem cadastrados |
| **Negócios Fechados** | Negócios marcados como ganhos |
| **Valor em Pipeline** | Soma dos negócios que ainda estão abertos — o dinheiro em jogo |
| **Receita Mensal** | Entradas registradas no período |
| **Despesas Mensais** | Saídas registradas no período |

**Valor em Pipeline** é a previsão de vendas: ele considera apenas negócios em andamento. Quando um negócio é ganho ou perdido, ele sai dessa conta.

## Os gráficos

**Evolução financeira.** Receitas e despesas lado a lado ao longo dos meses. Serve para enxergar tendência, não o saldo do dia — para saldo, use **Financeiro › Relatórios**.

**Funil de leads.** Quantos leads existem em cada estágio, do primeiro contato à conversão. Um degrau muito estreito indica onde as oportunidades estão travando.

**Rentabilidade de projetos.** Compara orçamento e custo por projeto. Projetos em que o custo se aproxima do orçamento merecem atenção.

**Propostas.** Volume e situação das propostas emitidas.

## Listas de acompanhamento

Abaixo dos gráficos ficam as **tarefas recentes** e as **comissões recentes**, para você retomar o trabalho sem procurar nos módulos.

## Se um gráfico aparecer vazio

Gráfico sem dados quase sempre significa que ainda não há registros no período escolhido — troque o período para conferir. Se aparecer uma mensagem de erro no lugar do gráfico, recarregue a página; persistindo, avise o administrador.
